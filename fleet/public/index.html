OUTBOUND CONNECTIONS
Bring a device into your fleet
Install Node.js 22.12 or newer, clone the fork, and install the agent dependencies. Pairing codes expire after 10 minutes and can be used once.
  1. Clone the project and install its fleet package.
  2. Install DesktopCommanderMCP on the device.
  3. Click Pair device and run the generated agent command.
  4. Keep the agent running with your platform's service manager.
The central service can move to another Linux host or container. Device agents need only HTTPS access to its address; no inbound device ports are required.
Linux and Windows use Node.js. Android requires a compatible Node.js environment such as Termux; this is not a native Android APK.
